# Release Notes

## Project overview to date - 2026-08-23
- Turn natural-language requests into macOS Zsh commands through OpenRouter in single-prompt or context-aware interactive sessions.
- Analyze, summarize, or transform up to 64 KB of piped command output with an optional plain-language prompt.
- Review generated commands before execution, with options to approve, cancel, skip, or run an instruction first; a limited set of read-only commands can run directly in interactive mode.
- Choose an OpenRouter model and light or dark terminal theme from command-line options or persistent configuration in `~/.ask/config`.
- Build and install the optimized Rust command-line binary from source with Cargo or the included Makefile.
